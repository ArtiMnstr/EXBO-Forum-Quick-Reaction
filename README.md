# EXBO Forum Quick Reaction

Быстрые реакции для официального форума EXBO — [forum.exbo.net](https://forum.exbo.net/).

Расширение позволяет ставить выбранные реакции на посты форума, не открывая каждый раз полный список реакций.

## Возможности

- Быстрая установка выбранной реакции отдельной кнопкой на посте.
- Активация реакции двойным щелчком — можно выбрать этот способ или включить оба.
- Настраиваемый хоткей для реакции на наведённом посте.
- Каталог реакций с поиском и избранными реакциями.
- Необязательная кнопка быстрого ответа с редактируемым текстом.
- Счётчик поставленных реакций: всего и за сегодня. Его можно включить или скрыть.
- Топ используемых реакций за всё время.
- Автоматическое сохранение настроек и статистики между запусками браузера.
- Возможность временно отключить расширение из окна управления.

## Установка

1. Скачайте **Source code (zip)** в разделе Releases и распакуйте архив.
2. Откройте `chrome://extensions` в Google Chrome.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой находится `manifest.json`.
5. Откройте или обновите [forum.exbo.net](https://forum.exbo.net/).

## Область работы и разрешения

Расширение предназначено для работы на [forum.exbo.net](https://forum.exbo.net/). Оно использует разрешение Chrome Storage для сохранения настроек и статистики. Поддержка других сайтов не заявляется.

EXBO Forum Quick Reaction — независимое пользовательское расширение. Оно не разработано, не поддерживается и не является официальным продуктом компании EXBO. По вопросам работы расширения обращайтесь к его автору, а не в поддержку EXBO.
